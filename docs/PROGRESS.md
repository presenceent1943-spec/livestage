# LIVE STAGE v2 — 진행 기록 (브랜치 `v2-demo`)

이 문서는 세션이 끊겨도 이어서 작업할 수 있도록 상태를 남기는 곳입니다. 최신 항목이 위.

## 실행 방법
- 로컬: `python3 -m http.server 8787` → http://localhost:8787/ (ES 모듈이라 file:// 로는 열리지 않음)
- 시연 모드가 기본. 서버 모드는 헤더의 모드 배지 → "서버 연동 모드" (Supabase 로그인 필요)
- OBS 오버레이: `overlay.html?stream=d1&scale=1.5&pos=tr&theme=dark&test=1` (test=1 이면 효과 테스트 바)
- 3분 시연: 홈의 "3분 시연 시작" 또는 `#/home?tour=1`

## 구조 (v2)
`index.html`(셸) → `app/main.js`(라우터·헤더·모드) → `app/views/*.js`(화면) / `app/data.js`(시연·서버 데이터 계층) / `app/engine.js`(순위·라운드·미션·정산 계산) / `app/excel-board.js`(순위판·효과, 뷰어·OBS 공용) / `app/tokens.css`(디자인 토큰·컴포넌트). 규약: `docs/V2-GUIDE.md`. v1 앱은 `legacy/index-v1.html` 로 보존.

## DB migration 적용 순서 (Supabase SQL Editor)
v1 `schema.sql` → v2 payments → v3 → v4 → v5 → v6 secure_publish → v7 excel → **v8 `schema_v8_v2demo.sql`**(팀전·규칙·메모, 출연자 수정/정렬/비활성화, 라운드 일시정지, 신고·제재·감사 기록). v8 미적용 시 서버 모드에서 해당 기능은 "지원 안 함" 안내로 비활성.
